# Bio

Репозиторий с исходным кодом одностраничного сайта-визитки.  
Демо-версия доступна по адресу [vercel](https://bio-gamma-tawny.vercel.app)/[git-pages](https://owenpwer.github.io/bio/)

## Содержание страницы
Сайт отображает:
- аватар
- имя и краткое описание рода деятельности
- набор ссылок на внешние профили

## Используемые технологии
[Tailwind CSS](https://tailwindcss.com) — утилитарный CSS-фреймворк
[Vercel](https://vercel.com) — хостинг и автоматический деплой из ветки `main`
