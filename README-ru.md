# 🌌 Owen Yaku Pers — Персональная страница-визитка

> 🇬🇧 [Read in English / Читать на английском](./README.md)

Данный репозиторий содержит исходный код персональной страницы-визитки (link-in-bio). 

Проект реализован на базе React и Vite без использования тяжеловесных фреймворков (таких как Next.js). Ключевыми особенностями являются интеграция статуса Discord в реальном времени и интерактивный фон на базе Canvas, реагирующий на движение курсора. При разработке особое внимание уделялось производительности и доступности (A11y) для обеспечения высокой скорости работы даже на маломощных устройствах.

## ✨ Ключевые особенности

- **Статус Discord в реальном времени:** Статусы (Online, Idle, DND, Offline) обновляются мгновенно благодаря интеграции с [Lanyard API](https://github.com/Phineas/lanyard).
- **Интерактивный фон:** Отрисовка созвездия из частиц на элементе `<canvas>`. Частицы взаимодействуют друг с другом и реагируют на позицию курсора.
- **Оптимизация производительности:** 
  - Отрисовка анимации приостанавливается при скрытии вкладки браузера.
  - WebSocket-соединения и Canvas корректно очищают ресурсы при размонтировании компонентов (предотвращение утечек памяти).
  - Удалены ресурсоемкие CSS-фильтры (`backdrop-blur`), создававшие избыточную нагрузку на GPU.
- **Доступность (A11y):** 
  - Навигация по вкладкам (Tabs) реализована в соответствии со стандартом WAI-ARIA (поддерживается управление с клавиатуры: `←`, `→`, `Home`, `End`).
  - Изменения статуса Discord озвучиваются скринридерами (`role="status"`).
  - Анимация отключается при активированной системной настройке `prefers-reduced-motion`.
- **Модульная архитектура:** Бизнес-логика инкапсулирована в кастомных хуках, интерфейс разделен на изолированные компоненты.

## 🛠️ Технологический стек

- **Ядро:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **Анимации:** [Framer Motion](https://www.framer.com/motion/)
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Интеграция:** Lanyard (WebSocket)

## 🚀 Локальный запуск

Требуется установленный Node.js (версия 18 или выше).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-ник/bio.git
   cd bio
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте `http://localhost:5173` в браузере.

## ⚙️ Конфигурация Discord

Для использования шаблона с вашим аккаунтом Discord выполните следующие шаги:
1. Присоединитесь к официальному [Discord-серверу Lanyard](https://discord.gg/lanyard) (обязательное условие для работы API).
2. Включите «Режим разработчика» в настройках Discord, нажмите правой кнопкой мыши на свой аватар и выберите «Копировать ID».
3. Откройте файл `src/App.jsx` и замените значение константы:
   ```javascript
   const DISCORD_USER_ID = 'ВАШ_ID';
   ```
